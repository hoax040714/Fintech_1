# 最终合并大表数据目录

本目录逐列核对当前 `prices.parquet` 的实际结构，并按 `data.py` 的现有逻辑解释含义；不修改数据、模型或网页。

## 表的基本情况

主文件：`D:/Fintech_1/data/prices.parquet`。原有 `prices.csv` 保留相同的215列业务数据；Parquet保存了类型信息、压缩后体积更小。

当前快照共 **471,813行、215列、300只股票**，日期为 **2020-01-02 至 2026-10-13**。这是实际文件范围，不代表已经获取到本文生成当天的收盘数据。

每行代表“一只股票在一个A股交易日的记录”，`date + code` 已检查为唯一键。股票来自当前取得的沪深300成分股池；不是逐历史日重建的沪深300成分名单，也不是300只股票每天都必然有记录。

| 数据类别 | 列数 | 主要内容 |
| --- | ---: | --- |
| 个股标识与日行情 | 10 | 日期、代码、名称、前复权OHLC、量额、换手率 |
| 行业匹配与行情 | 8 | 申万一级行业及其指数行情、日收益率 |
| 大盘匹配与行情 | 7 | 沪深300行情与日收益率 |
| A股日历与匹配时点 | 15 | 星期、月份、月首月末、休市间隔、09:00快照 |
| 宏观、利率与利差 | 26 | SHIBOR、中美国债收益率、期限利差、GDP同比 |
| 全球指数 | 120 | 12个指数，每个10列 |
| 基本面、估值与分红 | 29 | 财报、未复权收盘价、PE、PB、B/M、股息等 |
| 合计 | 215 | 不含模型训练生成的因子、标签、预测或回测结果 |

## 阅读口径

**比例单位不能混用。** `_pct` 为百分数值，例如5表示5%；`turnover`、`industry_return_1d`、`market_return_1d`是小数比例，例如0.05表示5%；`_pp`为百分点，例如3%−2%=1个百分点。`pe_ttm`、`pb`是倍数，`book_to_market`是比值。

**09:00只用于部分新增信息的回看匹配，不是整张表可交易的时间。** 财报、宏观和全球指数按 `available_at ≤ signal_time` 回看；但是个股、行业、大盘的当日OHLC和当日收盘估值（包括PE-TTM）要到当日收盘后才能使用。PE-TTM按当日日期匹配，不归入09:00回看。当前大表仍然面向原项目的收盘后分析场景，不能整体当成当天开盘前已知数据。

**日期与类型。** 下表“原始列号”是Parquet中的1起算位置。`timestamp[ns]`保存日期/时间；可用时点和 `signal_time` 已转换成北京时间墙上时间，但文件类型本身不带时区。海外 `source_date` 则是当地交易日期。`double`是浮点数，`int64`是整数，`string`是字符串，`bool`是布尔值。部分0/1标志或计数存成double，是为了容纳空值，并非允许任意小数。

## 全球指数（120列）

字段统一采用 `global_指数标识_字段后缀`，下文展开全部120个真实列名。数据来自Yahoo免费日线，交易所日历用于判断可用时点、夏令时及休市；不会把同名海外日期上尚未收盘的数据直接塞入A股盘前。

价格保持各原指数编制口径，未统一成价格收益或全收益口径，也未进行汇率换算；不要直接把不同指数的点位作横向价格比较。VIX是波动率指数。各指数关联成交量的统计口径也不统一。欧洲斯托克50借用XETR日历，VIX等使用保守日历与缓冲，并非每个品种专属交易时段的精确还原。

`new_sessions`数的是相邻A股09:00时点之间“预期应有的海外交易日”，而不是本地成功下载的报价条数。缺失的预期日线保留为空；`missing_flag`还会提示两个A股快照之间出现过的缺报，不仅检查当前行。海外休市而连续多个A股交易日匹配到同一条旧报价，是回看匹配，不等同于人为补出一条海外新行情。

## 合并关系与数据来源

个股行情以 `date + code` 为底表。用 `code` 接上当前申万一级行业，再用 `date + industry` 接行业日行情；沪深300行情按 `date` 接入。同一天的市场、宏观、日历、全球指数背景会重复出现在多只股票行中，这是股票—日期面板的正常结构，不代表新增了独立宏观观察值。

日历、宏观、全球指数先按A股交易日期构造每日背景表，再并入个股。财报按股票分别回看匹配；未复权收盘价按 `date + code` 匹配。保留原有股票行，不要求每只股票都具备所有财务指标。

| 类别 | 当前来源及处理 |
| --- | --- |
| 股票池及行业映射 | AkShare：沪深300最新成分表、申万一级行业及成分表；采用当前映射，存在历史样本选择/幸存者偏差 |
| 个股日行情 | AkShare/新浪：前复权OHLC；成交量、成交额、换手率保留原始口径 |
| 行业与大盘 | AkShare：申万行业指数、沪深300新浪指数日线 |

| 估值用价格 | 已有AkShare/新浪未复权缓存，加上腾讯免费日线；逐行保留来源字段 |

## 需要特别注意的边界

**GDP存在停更。** 当前主表匹配到的最新GDP真实公布日期为 **2025-07-15**。在最后一个A股日期2026-10-13上，它已相隔455个自然日，因此不能把该列解释成2026年最新季度增速。较新的季度GDP原始表另存于 `gdp_quarterly.parquet`，因未核实公布时间，没有并入历史大表；GDP总量列也不在这215列中。

**财报并非完整历史版本库。** 可用时间取公告日、更新日的较晚者再推迟到次日09:00，避免把后续修订数据放回最初公告日；但免费接口仍不是保存全部原始披露版本的严格point-in-time数据库。较晚更新可能造成部分财报匹配明显滞后。`financial_age_days`衡量报告期末距今的时间，不能当作公告滞后天数。

**PE已于2026-10-18改为TTM口径。** 原pe_static列被pe_ttm替换，不是仅修改列名；新值来自东方财富每日PE(TTM)。原年报日期和全年EPS仍保留为基础财务数据，但不再用来计算PE。来源历史估值不保证是无修订的严格point-in-time版本，不能仅凭日频日期就宣称没有前视偏差。PB和B/M仍按已披露每股净资产及当日未复权价格计算，送转等股份变化后未额外统一每股基数。流通股本仅由成交量/换手率估计，不是总市值或总股本。

**分红的时间口径。** 每条已实施分红的生效日取 `max(公告日+1自然日, 除权除息日)`，税前每10股派息除以10换算为每股；按区间 `(当日−365自然日, 当日]` 滚动累计。成功查询且无分红事件记0；下载失败不能解释成0。它是过去分红，不是未来一年预计分红，也不是现金到账日统计。

**空值不统一代表0。** PE-TTM源值非正或缺失时保留为空；原始每日估值缓存保留源值，包括负值。每股净资产非正时PB/B/M为空；部分行业财务项不适用，早期披露缺失、海外报价缺失也可能为空。不能直接把这些情况全填0。日历相关未来休市标志来自当前日历，不是对当时临时休市预知能力的还原。

**这不是最终训练特征清单。** 大表包括基础观察值、简单估值/日历派生值和匹配元数据。`features.csv`中的因子、未来收益标签，以及模型预测、评估、回测输出，不在这215列内。股票/行业名称、来源字符串、日期和质量标记也不能不加选择地当成数值因子送入模型。
