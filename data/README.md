# 本地数据目录

本目录保存原始行情、行业与大盘、基本面、宏观、日历、全球指数、因子和下载缓存，不随Git提交。这里只上传本说明和 `合并大表数据目录.md`，后者包含当前合并表215列的名称、含义、单位和时间口径。

克隆代码不会自动下载数据。可向团队负责人获取相同版本的数据包，或在项目根目录执行 `python main.py --data-only` 自行获取；该命令会访问外部接口，并更新本地数据。完整训练后才生成模型结果和网页需要的预测、评估、回测文件。

合并表有 `prices.csv` 和 `prices.parquet`。当前部分模型/网页逻辑仍读取CSV，不能只复制Parquet就省略CSV。当前PE字段为东方财富每日估值的 `pe_ttm`，不再是静态PE；更多口径与历史数据限制见字段目录。

共享数据时注明截止日、股票池、代码提交版本和是否包含结果。不要把备份目录、密钥、数据包和训练结果加进Git。
